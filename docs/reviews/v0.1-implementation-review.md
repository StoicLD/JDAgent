修复还覆盖了重复 Tool Call ID 在副作用前失败、异常信息清理、工具取消不产生虚假完成事件、
resume 后权限/工具/停止原因投影，以及 Tool Call 参数的上下文预算计数。

完成度审计随后补充了 Fake Model 可编程真实延迟、独立审批拒绝测试、workspace 外读写、CLI
超时/硬上下文配置、安全结构化 Trace 和 Fake 模型超时练习；当前完整门禁数字已反映这些
增量改动。

最终 Standards 复核还发现非法超时/上下文配置可能在 Session 创建后才失败；
`RuntimeConfiguration` 现统一校验有限正数、非负 Fake 延迟和正调用上限，并由 CLI 回归测试
证明非法配置不会创建 Session 目录。
