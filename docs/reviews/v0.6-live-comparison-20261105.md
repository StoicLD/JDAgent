## 复现、修复与复验

将既有控制器的完整六次离线流程改成从相对实验目录启动，其他行为不变。修复前两个参数化用例
均在 B1 失败，实际验证子进程复现同类状态记录缺失；此前测试只使用绝对 tmp_path，没有覆盖
操作说明中的相对路径入口。

根因在 [CommandLogs](../../src/jdagent/tools/command_output.py)：构造时保留了相对 root，随后把
相对 process.json 交给已切换 cwd 的 Windows 监督进程。修复在日志模块入口将 root 解析为绝对
路径，所有输出、状态、读取和容量锁使用同一个目录。这也覆盖产品 `--data-dir` 使用相对目录的
同类情形；没有改变命令权限、工作区边界或未知副作用规则。

修复后控制器、统一任务、v0.4 命令、四组合工具及强退恢复共 **67 passed，65.33 秒**。
两种后端的六次假 HTTP 流程都实际运行本地验证程序，并检查成功退出、保护文件和预算。
全量 Ruff 格式（302 个文件）／Lint、Pyright strict 通过。修复前后 XML 见
[定向证据](evidence/v0.6-20261105/implementation-relative-command/README.md)。
这次没有重跑完整套件；之前 545 passed／1 个既有 RAG 失败的结果仍按其 revision 单独记录。
