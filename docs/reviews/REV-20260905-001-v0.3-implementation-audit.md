## 结论

验收结论：`fail`。v0.3 已有可工作的 P1 纵向实现，但与已批准方案相比，真实 RAG 配置、
来源恢复与物理删除、历史 Citation、Eval 仍有缺口，不能将“代码合入 0.3.0”解释为完整工程验收。

本轮修复七类问题：来源索引身份覆盖、历史可见区间与重新启用、跨知识库生命周期操作、混合模式
Embedding 分组、HTTP Embedding 数据校验、Eval 来源假阳性，以及失败 Saga 的激活/回退保护。
新增 25 个测试场景。最终完整离线结果为 **197 passed、1 failed、5 skipped**；格式、Lint、
Pyright strict 通过。唯一失败是正确计分后暴露的已有检索质量缺口，未降低门槛、修改 Gold 答案或跳过该测试。

普通对话、Tool Call、权限、Session v2、取消、恢复、CLI/入口等已有离线回归未失败。真实 Milvus、
DeepSeek、Embedding 与 clean-env wheel 本轮未复验，因此不能外推为真实部署无回归。
