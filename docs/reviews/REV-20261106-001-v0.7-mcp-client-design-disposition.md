## 核对依据与保留判断

1. [ToolRuntime](../../src/jdagent/tools/runtime.py)默认 10 秒，已有 manages_timeout，但 _settle 没有上限。
   [ToolOutcome](../../src/jdagent/domain/tools.py)的 requires_stop 可与 effect 分开；effect=none 并不意味着从未发送。
2. [TurnInstructions](../../src/jdagent/instructions.py)除三个路径字段还会扫描 args，来源区分必须覆盖整个发现入口。
3. [恢复分类](../../src/jdagent/application/session_recovery.py)与[未完成调用补全](../../src/jdagent/eventing.py)
   当前用风险级别区分未知写／可安全中断，不能直接表达“只读但远端仍可能执行”的新事实。
4. [消息投影](../../src/jdagent/context.py)、[压缩](../../src/jdagent/context_runtime.py)及
   [记忆作业](../../src/jdagent/maintenance.py)需要同一来源和预览合同，不能只在 MCP 返回处截断。
5. 当前注册表未提供动态修改接口；规格 R0 的请求快照和空闲刷新已经正确表达目标，需要的是具体衔接方式。
6. [Coordinator](../../src/jdagent/application/coordinator.py)的 /compact 当前在批次后处理；/context-window 是只读预览。
   不能把两者一并视为会修改执行条件，审批命令也不能一律暂停。
7. [SessionCatalog](../../src/jdagent/application/session_catalog.py)会因单项失败中断列表，但新 Schema 尚未选定。
   “不擅自迁移”不等于“永远不能兼容读取”，读取、迁移和忽略未知事实分别处理。
