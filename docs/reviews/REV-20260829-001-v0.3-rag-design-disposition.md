## 复核补充的核心缺口

### Turn-scoped Evidence Reference

历史 Assistant Markdown 会进入下一 Turn，简单复用 `[E1]` 会把旧引用误解析成当前 Evidence。机器
Reference 必须携带 Turn token；Presenter 另行渲染用户可见短标签。

### 多 Embedding Profile

不同知识库可能使用不同模型、维度或归一化合同。Effective Knowledge Bases 必须按完整 Embedding
Profile fingerprint 分组，每组向量化一次；失败只影响该组，跨库只融合排名。

### Parsed Source Snapshot 版本

Parser/Locator 升级不应制造内容未变化的新 Source Version。Parsed Source Snapshot 是 Source
Version 的版本化派生物，由 Source Version、Parser Profile 和 Locator Schema 共同标识；Generation
指向与自己合同匹配的 Snapshot。
