# v0.4 工具执行语境

状态：`Proposed`

本词汇表限定 JDAgent v0.4 工具执行中的领域用语。对应取舍记录于
[设计讨论](../plans/v0.4-tool-execution-design-discussion.md)，不在词汇表保存实现细节或验收规格。

## 信任与执行范围

**受信任工作区（Trusted Workspace）**：
项目所有者允许在宿主用户权限下执行其中项目代码的工作区。该信任不自动授予具体工具调用的
执行许可，也不表示工作区或所启动进程受沙箱隔离。
_避免使用_：沙箱工作区、已获准执行的工具。

## 工具范围与许可

**已注册工具（Registered Tool）**：
系统已接入并能够按工具标识找到其定义与执行实现的工具。注册本身不说明它是否向当前轮次开放。
_避免使用_：本轮可用工具、已批准工具。

**本轮可用工具（Available Tool）**：
由用户或宿主选定、在当前轮次能力范围内开放的已注册工具。可用性不代表某次具体调用已经获准。
_避免使用_：已获准执行、自动允许。

**获准调用（Authorized Invocation）**：
通过适用权限检查，并在需要时取得审批的具体工具调用。许可的对象是调用，不能仅凭工具已注册
或处于本轮能力范围推断许可成立。
_避免使用_：已注册工具、本轮可用工具。

**工具能力范围（Tool Capability Scope）**：
用户或宿主为一轮交互选定的工具能力边界，包括分析、编辑、执行三档递增范围。它限定本轮可用
能力，不表示其中所有调用都已获准。
_避免使用_：权限批准、沙箱级别。

**Session 命令允许规则（Session Command Allow Rule）**：
用户在一个 Session 内明确授予的命令许可范围，以固定程序和参数前缀界定，并约束工作目录与
执行环境。命中规则的调用可以免于再次交互审批，但仍受本轮能力范围与权限上限约束。
_避免使用_：模型判定的相似命令、所有命令免审、沙箱许可。

## 文件修改前提

**读取版本（Read Revision）**：
一次文件读取所对应完整文件内容的版本标识。精确编辑以它约束允许修改的文件版本，即使读取
只返回某个片段，修改前提仍针对完整文件。
_避免使用_：已读行号、路径、写入许可。

**编辑批次（Edit Batch）**：
针对同一文件、基于同一读取版本的一组精确替换。批次中的修改作为一个提交单元，不表示不同
文件之间存在事务。
_避免使用_：跨文件事务、逐项成功即提交。

## 执行证据

**命令输出日志（Command Output Log）**：
归属于一次命令调用及其 Session、可在恢复 Session 后继续查看的已保存输出。它与提供给模型
的有限预览不同；保存范围受容量限制，不能把已有日志理解为一定保留了全部输出。
_避免使用_：完整输出保证、模型上下文、重跑结果。
