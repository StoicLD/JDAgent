## 学习者初始模型

用户最初认为上下文是每次发送给大模型的输入，包含系统指令、Role、用户消息和其他消息；Skill
暂不实现。上下文应能感知 AGENTS.md 等配置变化；窗口可能有 272K、500K、1M 一类预设值，
需要 token 预算；接近 90% 或动态阈值时压缩，但压缩策略仍不清楚。

这是原始认知记录，不回填后续讨论得到的答案。初始的两个完整候选方案、三个故障预测尚未由学习者
独立提交，不能因访谈完成而视为学习出口完成。

## 术语

| 术语 | 本项目含义 |
| --- | --- |
| Session | 可恢复的会话及其持久事件序列，不等于一次模型请求 |
| Turn | 一次用户输入到最终完成的执行过程，可含多次模型和工具调用 |
| Context | 某一次模型请求实际包含的逻辑输入投影 |
| Context window | 模型可容纳的输入与输出范围；不是磁盘历史大小 |
| 可用输入预算 B | 总窗口扣输出和安全预留后，再受独立输入上限约束的容量 |
| 原文档案 | 本地保存的完整会话消息、结果和重建材料 |
| 原文保护区 | 本次投影中不允许有损改写的关键原文，有来源和保留理由 |
| 分段摘要 | 对一段完整历史的有损表示，保留来源范围且版本不可变 |
| 压缩 checkpoint | 已提交的摘要、原文保护区和尾部选择方案，不是工具执行恢复事实 |
| RequestManifest | 一次逻辑请求的内容、顺序、版本与计数清单，不包含网络凭证 |
| Memory | 有来源、作用域、版本与有效状态的持久陈述 |
| Recall | 从当前有效 Memory 中选出与任务相关的内容 |
| 停用 | 不再自动使用，同时保留记录并阻止旧来源复活 |
| watermark | 已处理的来源版本位置；空提取也记录，防止重复调用 |
| lease | 后台作业或活跃会话的限时占用标记，崩溃后可超时恢复 |
