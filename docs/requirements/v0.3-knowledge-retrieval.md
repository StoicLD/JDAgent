## 目标

JDAgent 从当前 Workspace 获准使用的知识库中检索 Evidence，在预算内提供给生成模型，并返回可核验
的 Citation；无 Evidence 支持的内容必须明确表示为 Model Supplement。知识库不可用与证据不足必须
可区分。普通 Agent 启动与无 Binding 对话不依赖 Milvus、Embedding 或 RAG extra。

## 用户场景

1. 用户注册 Knowledge Connection、创建知识库，并把知识库绑定到当前 Workspace。
2. 用户显式摄取 TXT、Markdown 或 CSV；系统形成不可变 Source Version 与可定位 Snapshot。
3. 用户提问后，Runtime 使用本 Turn 冻结的 Binding 与激活 Revision 检索一次，全 Turn 复用同一
   Prepared Turn Knowledge。
4. 用户看到有 Citation 的知识主张，以及单独分区的 Model Supplement；删除后来源显示墓碑。
5. 开发者用 Fake Catalog/Store/Index/Embedding 离线复现正常、空、失败、取消和损坏路径。
6. 学习者能闭卷解释 Catalog、Source Version、Generation、Revision、PTK、TRR 与 Citation 的所有权。

## 功能需求

### FR-001 Knowledge Catalog 与访问授权

- 用户级 SQLite Catalog 保存 Connection、Knowledge Base、Binding、身份与激活指针。
- Connection：register / test / list / remove；KB：create / list / status / delete；
  Binding：bind / unbind / list。
- Binding 按 Workspace Identity 分区；注册 Connection 不自动授权任何 Workspace。
- Catalog 损坏时知识模块 fail closed；普通 Agent 继续运行且不得打开或 Ping 知识外部依赖。
- Schema Migration 前必须 Online Backup 且校验成功。
- 秘密只以 `credential_ref` 保存，不得写入 Catalog、Session、Trace 或错误正文。

验收：AC-001 … AC-008。里程碑：M1。

### FR-002 确定性来源解析

- Raw Source Artifact 内容寻址、原子写入、Hash 校验；Store 只拥有不可变字节。
- 编码：显式 Codec 优先，否则 BOM → strict UTF-8 → charset-normalizer；歧义、解码失败或替换
  字符使该文件失败。
- Parser：TXT 段落、Markdown 结构（标题/列表/引用/围栏代码/表格）、CSV（必需 Header，行=Parent，
  单元格=Child，行列 Locator）。
- Parent-Child Chunking：结构完整 Child 默认无 Overlap；仅长度强制切分允许有限 Overlap。
- 固定输入产生稳定 Snapshot 身份与 Locator；Locator 往返 100%。

验收：AC-009 … AC-016。里程碑：M2。

### FR-003 索引与来源生命周期

- EmbeddingPort：独立 OpenAI-compatible HTTP Adapter；文档与 Query 使用同一 Profile；Fake 走同一
  调用路径。
- Knowledge Index 是可重建投影；Catalog 物理 Collection 映射是唯一读目标；Revision Filter 在
  top-K 前应用。
- Add/Replace 为每文件 all-or-nothing Saga；失败时旧版本继续可读。
- Deactivate 可逆排除且不墓碑；Delete 在激活排除 Revision 的同一短事务进入 `DELETE_PENDING` 并
  立即墓碑；物理清理完成后 `DELETED`；对象意外缺失是损坏不是删除。
- 用户级 Catalog 同一时刻一个 Mutation Lease；TTL/Heartbeat/过期接管/幂等重试/Reconcile。

验收：AC-017 … AC-028。里程碑：M3。

### FR-004 Retrieval 与 Prepared Turn Knowledge

- Turn Knowledge Preparation 冻结 Binding 与每库 Generation/Revision/物理映射。
- 按完整 Embedding Profile fingerprint 分组；每组每 Turn 一份 Query Vector。
- 单库 BM25-only、Dense-only、Hybrid+RRF 可独立运行；跨库等权排名融合；成功空结果计入成功。
- Parent Expansion、去重、三层预算后形成不可变 PTK 与穷尽 Turn Retrieval Outcome。
- 可选全局 Reranker 默认关闭；失败固定回退融合候选并记录 Turn-level degradation。
- 不修改 Agent Loop 内部检索；Preparation 对 Loop 只暴露 PTK。

验收：AC-029 … AC-036。里程碑：M4。

### FR-005 Runtime Event / Headless v2 与 Citation

- 新 Session 只写 schema v2；v1 resume 为 `unsupported_schema`；未知 Schema 同样 Unsupported，
  不是 Corrupt Tail，不得被尾行恢复截断。
- 顺序：`user_message` → 准备 PTK → `turn_retrieval_recorded` → 模型循环 → 通过校验后才写
  `assistant_message_completed`（独占结构化 Citation）→ `turn_completed`；失败写 `turn_failed`。
- ContextBuilder = f(events, current PTK, capabilities)；同一 Turn 复用 PTK。
- Evidence Reference 含 Turn token；拒绝未知、跨 Turn、被裁剪和原文伪造引用；最多一次 Repair，
  不重新检索、不扩大 Evidence、不执行 Tool。
- Repair 耗尽：`turn_failed(model_error, invalid_citation)`，模型边界 `invalid_response`。
- 无 Binding：`NOT_CONFIGURED`，不连接 Milvus。
- Headless v2 输出 `knowledge.outcome`、`knowledge.bases[]`、`citations[]`、`model_supplement`。
- 进程在 TRR 后崩溃不重水合 PTK；写 `turn_failed(cancelled, process_interrupted)`。

验收：AC-037 … AC-048。里程碑：M5。

### FR-006 Eval、安装与故障矩阵

- Gold Corpus 覆盖中英/CSV/结构/冲突/无答案/注入/多库/生命周期。
- 先记录无 RAG 基线；Child Retrieval 与 Final PTK 分开报告；Answer/Citation Live 每题 ≥3 次，
  禁止挑选最佳一次。
- 基础 wheel 不得因缺少 RAG extra 而无法启动无 Binding Agent；RAG extra 不得拉取
  PyTorch/Transformers。
- Live 矩阵与安装验证显式 opt-in，不记录 Query/Evidence/回答/秘密正文。

验收：AC-049 … AC-056。里程碑：M6。

### FR-007 安全边界（横切）

- 知识管理不得注册到 Tool Registry；Evidence 不能改变指令、工具、权限、Binding 或检索范围。
- 不自动打开 URL，不执行来源中的代码或命令。
- Prompt Injection 样本不得导致权限放宽；防护是边界控制，不宣称消除全部模型响应风险。

验收：AC-007、AC-047、AC-053。里程碑：M1/M5/M6。

### FR-008 可观察性（横切）

- Trace 记录 Operation/Turn/KB/Generation/Revision ID、阶段耗时、候选计数、预算、模式、指纹、
  稳定错误、Lease/Reconcile/Repair 状态。
- Trace 不记录 Query、Evidence、Source、CSV 单元格、回答正文、API Key、credential 解析值。

验收：AC-008、AC-048。里程碑：M1/M5。

## 非目标

与已批准架构 §2.2 和实施计划 §13 一致，明确不进入 v0.3：

- Query Rewrite、LLM Router、Agentic RAG、检索 Tool、Session 级知识选择；
- JSON/PDF/HTML/Excel、网页采集、文件监控、专用代码 Parser；
- MCP/外部 Provider 空壳、本地模型管理、多 Reranker、Milvus Distributed；
- 长期记忆、Context Orchestration、Compaction、多模态 Evidence；
- Runtime Event/Headless v1 双写、迁移或长期兼容；
- Grounded-only Answer 模式。

## 失败行为

- Catalog 损坏、未知 Schema、非法 Citation、编码歧义：fail closed，不静默修复。
- 单库失败保留身份与稳定原因：`BINDING_INVALID`、`ACCESS_DENIED`、`PROVIDER_UNAVAILABLE`、
  `QUERY_FAILED`。
- Outcome 使用 B/S/F/E 穷尽公式，不允许按“回答看起来有用”重解释。
- Mutation 失败：旧 Generation/Revision 继续可读；新版本验证并激活前不可见。
- 知识故障不等于 Agent 故障。
