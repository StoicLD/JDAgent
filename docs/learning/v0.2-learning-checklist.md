## B. 五条数据流口述

闭卷解释：

1. 普通 Prompt 如何从 Terminal 进入 Coordinator、Runtime Event、Presenter 并返回 `IDLE`。
2. `/resume` 为什么不进入模型，以及运行中为何不能切换 Session。
3. 一次 `write_text_file` 如何从 `ASK` 到审批视图、Session Rule、工具副作用和下一轮模型请求。
4. `Ctrl+C` 如何取消当前 Turn、保存终止事实并保持 Session 可继续。
5. Headless text/json 如何复用同一 Runtime，同时保持 stdout、stderr 和 ANSI 合同。

完成标准：

- [ ] 没有把 Interactive Application 误认为第二个 Agent Loop。
- [ ] 没有让 Terminal Adapter 判断权限或直接操作 JSONL。
- [ ] 能区分 Runtime Event 事实与 Presentation Model。
- [ ] 能说明 Session Rule 为什么属于 Permission Module，而不是审批 UI。
- [ ] 能说明 text/json 为什么需要独立 Presenter，而不是从 Rich 输出中去颜色。

## D. 强制关闭恢复实验

使用确定性故障测试或测试夹具分别制造：

1. 完整事件后的进程终止；
2. 合法事件前缀加最终半行；
3. 用户消息已保存但尚未越过副作用边界；
4. 写权限已批准、工具可能已执行但结果未保存；
5. JSONL 中间损坏。

只根据 Session 文件、恢复诊断和安全 Trace 回答：

- [ ] 哪些事件已通过 durability 边界？
- [ ] 哪种情况可以备份并截去最终半行？为什么中间损坏不行？
- [ ] 哪个 Turn 是最后安全 Turn？
- [ ] 为什么副作用不确定时既不能自动重试，也不能伪造失败？
- [ ] 异常恢复 Session 继承什么、不继承什么？
- [ ] 为什么异常恢复不等于文件系统回滚或通用 Session Branch？
