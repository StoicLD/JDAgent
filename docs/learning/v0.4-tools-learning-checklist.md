## F. 故障实验

每项均由学习者先写预测，再依据文件字节、进程状态、事件和日志判断；AI 不代答：

1. 读取后外部改动不相关行；编辑仍有唯一旧文本匹配。
2. 一个编辑批次中第二项不存在或与第一项重叠。
3. 审批期间改变文件、工作目录目标或执行环境。
4. 未获准调用伪造已注册工具名，或提交本轮未开放的命令工具调用。
5. 命令产生超量 stdout/stderr，同时长期等待或启动子进程。
6. 分别在提交之前、之后及进程清理期间取消；另模拟宿主异常结束。
7. Session 结果写入失败、日志容量耗尽、日志落盘失败及日志主动清理。
8. 命令明确失败两次，随后收到第三次恢复请求；判断预算和停止规则。

- [ ] 每项都区分继续决策、重新读取、需要人工判断和禁止盲目重试。
- [ ] 没有把“异步等待被取消”作为真实线程或进程停止的证据。
