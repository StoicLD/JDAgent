## 测试入口

优先从 AgentLoop 运行完整 Turn，替换已有 ModelPort、工具和 Session 边界，断言用户可观察的
输出、发给模型的逻辑请求、持久事件与真实副作用。不因内部函数拆分而重写验收。局部测试仅补充
无法在主入口清楚定位的 tokenizer 差异、路径发现、计时与存储故障。

现有测试基础：

- [AgentLoop](../../tests/test_agent_loop.py)、[ContextBuilder](../../tests/test_context_builder.py)、
  [v0.4 合同](../../tests/test_v04_contracts.py)覆盖请求、轮次与工具关联。
- [恢复](../../tests/test_session_recovery.py)、[强制退出恢复](../../tests/test_forced_exit_recovery.py)、
  [JSONL](../../tests/test_jsonl_session.py)覆盖持久状态和重启。
- [CLI 集成](../../tests/test_interactive_cli.py)、[CLI 子进程](../../tests/test_cli_subprocess.py)、
  [工具端到端](../../tests/test_v04_e2e.py)用于命令和任务结果。
- [来源版本回归](../../tests/test_source_revision_regressions.py)保护现有 KB 删除与历史引用合同。

新测试围绕这些入口扩展，不为每个内部组件增加公开 Port。Fake Model 验证调度和不变量，Live
Model 验证摘要语义、提取质量与真实计数，两种证据不能互相替代。

## 固定数据与基线

实施时建立专用测试数据集，全部使用合成历史，不读取用户真实会话。包含两个 workspace、独立
用户偏好、20 个历史 Session、60 个人工标注检索问题、明确来源和有效状态。至少一半问题用与
原文不同的表达；包括精确标识符、无答案、冲突、到期、停用后的同义改写与跨项目近似文本。

长任务固定步骤包括：早期禁止修改一个文件、要求只在指定目录写入、一次失败测试、一个待执行
计划、一段精确标识符、多次大输出、最终产物核验。离线模型容量缩小以强制同一 Turn 至少三次
压缩；Live 使用实际合法容量与足够输入，不伪造 Provider 限制或夸大“实测占满”。

基线 A 为固定 revision 上现有滑窗实现；同任务记录超限、约束丢失与完成情况。基线 B 为仅
关键词检索；与关键词+语义方案使用相同来源、问题和范围过滤。摘要策略比较至少包含“单一滚动
摘要”与“分段摘要+保护原文”，使用相同主模型、温度、预算和工具结果。

固定记录 revision、依赖、Provider/model、配置、提示模板版本、数据 hash、请求清单和重复次数。
v0.4 已有失败作为旧基线单独记录，不把新失败混入“历史已知”而跳过分析。
另将[首次 Live 漏 search_text](../reviews/v0.4-live-verification.md)作为 E37 的步骤遵循基线；
原记录没有谎称执行过该步骤，实验必须分别计量“遗漏步骤”和“摘要虚构完成”，不能合并成同一种失败。

## 指标和通过判据

正确性硬门禁：所有确定性场景通过；工具 call/result 配对、来源可解析、workspace 隔离、
停用不复活、恢复不重复副作用的违规数均为 0。任一失败阻止对应阶段完成。

Live 语义提案：同一固定长任务至少三次独立运行，逐次核对禁令保留、步骤状态与最终产物；每次
关键约束保持率为 100%，关键状态错误为 0，任务三次均完成。非关键摘要细节单独记录缺失率。
若某项失败须保留当次证据，调整方案后以新 revision 重跑，不能挑选最好的一次。

检索提案：标注集 Recall@5 不低于 0.90；无答案场景错误注入为 0；与关键词基线比较语义改写
子集，不以总体均分掩盖 ID 查询退化。记忆提取逐项核对理由与来源，错误提升全局作用域和无来源
有效记忆均为 0；其他精确率/召回率按类型报告，初始门槛在实现前冻结，不能看结果后回调。

同时报告压缩前后 E/B、达到 40% 比例、保护内容占比、主任务与维护输入/输出 tokens、重试次数、
总成本、压缩耗时与任务总耗时、后台延迟、索引检索 p50/p95、磁盘增长。价格以执行时配置来源
换算；拿不到价格只报告 token，不捏造金额。性能结果是取舍证据，不能覆盖正确性失败。

新增计量：E30 报实际输入与 E 的偏差及是否低估；E34 报持续追加与重开校验各自 p50/p95；后台
费用区分实测、预留和因崩溃未知的消耗。缓存项仅在 Provider 返回时计算命中比例，缺测标不可用。
F13 的缓存布局暂不固定优化方案：阶段四若对照证明布局有明显成本/延迟损失，再单独调整并重验
消息语义与调用配对，不能通过缓存优化改变指令优先级。

## 人工核验与证据

每份执行报告包含固定 revision、场景、运行命令、配置、预期、实际、失败判定、证据路径和剩余
限制。模型回答“已完成”不是证据，产物、工具结果和持久事实才是。人工抽样从摘要追到原文，
核对特别是负面约束、未完成步骤、失败与未知副作用。

学习者先为 E11、E12、E13、E18、E23 写预测，再运行专用夹具并解释差异。AI 可执行已经授权的
实验与整理证据，但不能代填人工理解或闭卷完成记录。本轮仅做文档结构、链接与需求覆盖核对，
不创建产品测试或宣称上述实验已通过。
