# v0.1 实施计划

状态：`Proposed`

## 前置条件

- [v0.1 需求](../requirements/v0.1-agent-runtime.md) 已于 2026-08-09 获得用户批准。
- 用户批准 [Agent Runtime 架构](../architecture/agent-runtime.md)、[ModelPort 设计](../architecture/model-port.md)、[Python 工程规范](../development/python-style.md) 和本实施计划。
- 确认 Python 包名和真实 DeepSeek 集成测试使用的模型配置。
- 创建并验证 `pyproject.toml`、`.python-version` 和开发工具配置；API Key 只由用户在本机安全提供。

## 实施原则

- 每个里程碑先编写失败测试或可执行验收，再实现最小行为。
- 默认测试只使用 Fake Model，不访问网络、不消耗真实 API。
- 每个阶段产生可观察 Trace，并由学习者解释入口、状态变化、失败和退出条件。
- 当前里程碑未通过前，不提前引入后续机制。

## 里程碑

### M0 Python 工程基线

- 建立 `src` layout、测试目录、uv 依赖和 Ruff/Pyright/Pytest 配置。
- 固化格式、Lint、严格类型和离线测试命令。
- 退出条件：空实现不需要业务脚手架，四项验证命令可重复运行。

### M1 领域类型、端口与 Fake Model

- 实现模型请求、事件、能力、错误和 `ModelPort`。
- 实现脚本化 `FakeModelPort`，覆盖文本、Tool Call、错误、超时和重复调用。
- 退出条件：Core 测试不导入任何真实 Provider SDK。

### M2 最小 Agent Loop

- 实现单轮文本、Tool Call 循环、稳定停止原因和调用上限。
- 先使用内存事件与 Fake Model 验证状态转换。
- 退出条件：普通回答、一次工具调用、多个串行工具调用和失控循环测试通过。

### M3 Tool Registry 与三个内置工具

- 实现工具定义、查找、Schema 校验、统一执行和 `ToolResult`。
- 实现 `calculator`、workspace 限定的 `read_text_file` 和 `write_text_file`。
- 退出条件：未知工具、非法参数、Handler 异常和路径逃逸在副作用前失败。

### M4 Permission Pipeline

- 实现 `ALLOW`、`ASK`、`DENY` 以及 CLI 审批 Adapter。
- 将审批请求和结果纳入事件流，拒绝结果返回模型。
- 退出条件：未经批准的写操作没有文件副作用，越界路径始终拒绝。

### M5 Session 与 JSONL Adapter

- 定义 `SessionPort` 和稳定事件，提供 append-only JSONL Adapter。
- 实现新建、加载、事件重放和 CLI resume。
- 退出条件：进程重启后恢复消息、工具、权限和停止原因；损坏尾部得到明确错误。

### M6 Context Builder 与 Trace

- 从 Session 投影构建标准 `ModelRequest`，加入预算估算和硬限制错误。
- 输出结构化 Trace、耗时、Usage、调用次数和停止原因。
- 退出条件：Agent Loop 不直接拼 Provider 请求，Trace 能解释完整 Turn。

### M7 DeepSeek Adapter

- 接入官方兼容 API，转换请求、流式文本、Tool Call、Usage 和错误。
- 加入显式 opt-in 集成测试，不在日志、快照或事件中保存凭据。
- 退出条件：真实普通回答和真实 Tool Call 闭环通过，默认测试仍完全离线。

### M8 集成验收与学习出口

- 运行格式、Lint、严格类型、单元测试和 opt-in 集成测试。
- 验证恢复、取消、上限、超时、权限和秘密清理。
- 学习者闭卷说明 ModelPort、Tool Runtime、Permission、Session 和 Context 的关系，并根据 Trace 定位一次注入故障。
- 固定 revision 后再请求 Cursor 独立评审。

## 测试矩阵

- 模型：文本、单/多 Tool Call、无效流、认证、限流、超时、上下文过长、取消。
- 工具：成功、未知、无效参数、异常、超时、路径逃逸、未批准副作用。
- 会话：新建、恢复、部分写入、损坏尾部、事件顺序和重复 call ID。
- 循环：正常停止、用户取消、模型/工具上限和错误传播。
- 安全：API Key 清理、workspace 解析、拒绝路径无副作用。

## 明确延后

MCP、RAG、长期记忆、上下文压缩、Shell、网络、浏览器、爬虫、Subagent、多 Agent、Task DAG、后台任务、Cron、Worktree 和 Web UI 不进入 v0.1。
