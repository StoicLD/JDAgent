## 实施细化

- 使用设计 §9 的初始限额；请求窗口默认 64,000，输出预留 4,096；以 UTF-8 字节数加消息
  开销作保守估计，逐个移除完整旧轮次。当前任务超限直接停止，不生成摘要。
- 新替换文本沿匹配区域的换行风格；区域没有换行时沿文件首个换行；混合区域拒绝。
  版本基于原始完整字节与规范路径，不忽略空格或大小写。
- 文件支持限定为普通本地文件；拒绝设备、ADS、链接、reparse point、多硬链接目标。
- 文件提交机制先通过 Windows 实验再接入；启动事实必须先保存，中断无法确认则标记未知。
- 命令环境只传宿主白名单；不传模型密钥。实现采用等待 stdin 指令的受信任 Python bootstrap，
  以 `-I -S` 禁用工作区导入与启动钩子；先将 bootstrap 加入 kill-on-close Job，再发送 argv。
  用户程序继承 Job，不能在建立进程树管理之前启动。拒绝 bat/cmd 直接启动，不隐式调用 Shell。
- 不自动清理用户旧 Session。新格式使用独立版本，清理入口仅作用于会话输出。

## 已落地的合同与机制

- 正常组合根暴露八个工具：calculator、find_files、read_file、search_text、create_file、
  edit_file、run_command、read_command_output。旧三工具工厂只供旧合同回归使用。
- `--tool-scope analyze|edit|execute` 默认 execute，在一轮内冻结。Analyze 可用纯计算、读取、
  发现、搜索和日志读取；Edit 增加创建/编辑；Execute 增加命令。超范围工具既不投影，也不能执行。
- 文件写入和命令默认 ASK；`--command-permission ask|deny` 不能覆盖用户/项目 DENY。
  既有 write_permission=deny 也禁止通过命令写入。审批显示完整准备后参数，包括旧/新文本；
  持久审批记录保存摘要及展示内容哈希。Session 命令规则匹配程序、cwd、环境指纹、非空参数前缀，
  用户确认后允许任意尾参。相同准备后调用在同轮被拒绝后不重复提示。
- 五个文件工具与两个命令工具均声明并验证成功结果 Schema；统一 ToolOutcome 分开记录
  completed、effect、observed_failure、cancelled、error_code、requires_stop。
  非零退出码是已完成但观察到失败；启动失败没有验证结论；未知副作用必须停止。
- 编辑先在独占句柄下校验完整文件 revision 并计算整批变更，再写入、truncate、flush/fsync。
  持有祖先目录的限制共享句柄防止路径替换，目标文件 share=0。冲突或批次匹配失败不写入。
  这是锁内原位提交，不承诺崩溃时原子替换或回滚；写入中断可能部分生效，必须标记未知并隔离恢复。
- 命令生命周期和输出落盘在工作线程执行；取消由信号通知工作线程，Runtime 持续等待清理，
  包括连续取消。Job 关闭杀死后代；超时、取消、残留后代或无法确认清理均阻止继续盲目执行。
  bootstrap 握手区分用户程序是否实际启动，缺少握手按未知处理。
- stdout/stderr 分别留存，单次合计 10 MiB、workspace 合计 100 MiB，预览合计 16 KiB。
  达限后继续排空进程管道并标记丢失，不静默删除旧日志；容量不足禁止新命令。
  `read_command_output` 按字节范围读取；`/logs clear` 只清当前 Session 的输出并保留 cleared 标记。
- schema_version=3，默认会话目录为 `sessions-v4`。旧目录原样保留，不自动导入或迁移。
  未开始的批内调用补 not_executed；已开始但未知的写入/命令保留未知事实。安全的进程中断恢复
  也补齐工具消息配对；未知副作用即使已经写入 turn_failed 仍隔离到新恢复 Session。
  恢复 Session 不继承许可，可只读访问来源 Session 命令日志；缺少最终元数据时显示 incomplete。
- 请求默认窗口 64,000、输出预留 4,096；普通历史与恢复快照均按完整旧轮次裁剪，
  记录省略标识而不删除事实。当前任务、工具定义、系统指令、当轮证据和输出预留不可裁剪。
  每轮最多 16 次模型调用、32 次工具调用、两次失败恢复；Citation repair 也纳入预算和取消处理。

Windows 机制依据：[Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)
与 [CreateFileW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew)。
这些机制约束受信任宿主上的协作操作，不提供不可信命令沙箱。
