## 依赖与边界

锁定结果包括 `langgraph 1.2.20`、`langchain-core 1.7.6`、`langchain-deepseek 1.1.1`、
`langchain-openai 1.7.4`、`openai 2.54.0`，准确依赖以 `uv.lock` 为准。
OpenAI SDK 限于 2.x：该版本满足 LangChain 的依赖要求，同时保留项目现有 httpx 传输和
MockTransport 注入接口；最初解析到的 SDK 3.46.0 采用 httpx2，本次不附带迁移该传输接口。
SDK 只是 DeepSeek 兼容协议的底层客户端，不代表调用 OpenAI 服务。

Adapter 使用每份请求自己的模型和参数；共享底层客户端、不修改请求快照。SDK 重试设为 0，
关闭 LangSmith 追踪继承；流尾用量只结算一次，完整工具参数用严格 JSON 校验，缺失结束证据不
推断成功。借用的 HTTP 客户端由调用方关闭，组合根登记自己拥有的关闭回调。

官方接口复核：[Graph API](https://docs.langchain.com/oss/python/langgraph/graph-api)、
[ChatDeepSeek](https://docs.langchain.com/oss/python/integrations/chat/deepseek)。
运行行为以锁定版本源码及本地假 HTTP 实验为准，不以在线示例代替验证。
